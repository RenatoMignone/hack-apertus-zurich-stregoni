# Stregoni at Hack Apertus Zurich

Team workspace for **Hack Apertus Zurich, 27–28 November 2026**, at the AI Startup Center, Technopark Zurich. The team will use this repository to prepare for the event and carry the confirmed brief, decisions and handoffs into the build.

**Zurich team** · [Renato Mignone](https://github.com/RenatoMignone), [Nicholas Bünger](https://github.com/nicholasbuenger) and Rozhina Ahmadi.

**Current state** · Preparing for the opening briefing. Sprintd assigns the challenge after teams rank their preferences on Friday morning. The assignment and partner workshop will guide the project scope, stack and submission repository.
