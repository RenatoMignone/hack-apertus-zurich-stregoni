# Liebefeld reference

At Hack Apertus Liebefeld (Bern), 18–19 October 2026, Stregoni won the Bern Economic Development Agency challenge and placed **second overall** with **B to Bern (B2Bern)**. The organizer's published results confirm the overall placement. [Organizer results](https://hackapertus.ch/regions/bern-liebefeld) · [Sprintd results](https://app.sprintd.org/events/hack-apertus-liebefeld) · [Project page](https://hackapertus.ch/projects/b2bern) · [Demo video](https://youtu.be/JwZZSQcDg2w)

B2Bern helped economic-development staff match companies' needs to researchers, groups, projects and infrastructure across the University of Bern, ARTORG and Diabetes Center Bern. Apertus v1.5 70B interpreted the company brief and helped produce a cited report. Hybrid retrieval surfaced source passages, and an operator reviewed the findings before exporting the report. [Team submission repository](https://github.com/Spaghetti-Overflow/hack-apertus-stregoni) · [Renato's project repository](https://github.com/RenatoMignone/hack-apertus-b2b)

## What to carry into Zurich

- **Give judges a short path to a working demo.** The Bern submission put the run instructions and verification evidence behind one judge-facing entry point. [Judge guide](https://github.com/Spaghetti-Overflow/hack-apertus-stregoni/tree/main/docs/judges)
- **Show one convincing case early.** Bern documented a full input-to-output story with inspectable sources, clear limits and a repeatable walkthrough. Keep this pattern where it fits the Zurich brief. [Bern case brief](https://github.com/Spaghetti-Overflow/hack-apertus-stregoni/blob/main/demo/case-brief.md)
- **Describe the mode you tested.** The Bern quickstart documented the fixture-based walkthrough and connected run separately, and the verification notes identified which checks exercised real inference. [Quickstart](https://github.com/Spaghetti-Overflow/hack-apertus-stregoni/blob/main/docs/judges/QUICKSTART.md) · [Verification](https://github.com/Spaghetti-Overflow/hack-apertus-stregoni/blob/main/docs/judges/VERIFICATION.md)

The two local Bern checkouts are `../../Bern/hack-apertus-liebefeld` (event preparation) and `../../Bern/hack-apertus-submission` (implementation and final package) relative to the Zurich repository root, when the workspace has the same directory layout. The public submission repository above is the portable reference. Use Zurich's assigned brief and template for all current implementation and submission decisions.
